# @cngeo/timeline

A histogram timeline over time-chunked map data: chunk descriptors of any
period, a chunk-set orchestrator, playback, and a canvas timeline component.
No map library; the MapLibre control and the PMTiles chunk format live in
`@cngeo/maplibre`.

**Status: under construction.** Nothing here is usable yet beyond `VERSION`.
The design is in
[`docs/superpowers/specs/2026-11-25-map-widgets-design.md`](../../docs/superpowers/specs/2026-11-25-map-widgets-design.md)
(Phase 4).
